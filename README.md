# twin

Kenel Belizaire's digital twin — an AI chatbot that answers questions about his career, background, skills, and experience.

- `backend/` — Python. A FastAPI chat API (`server.py`) with per-session conversation memory. Managed with [uv](https://docs.astral.sh/uv/).
- `frontend/` — Next.js site with its own chat UI and API route. See `frontend/README.md` for local development and Vercel deployment.
